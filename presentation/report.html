1. Executive Summary

Provera is an AI-powered fraud detection system that combines graph-based machine learning with large language model (LLM) agents to identify Medicare fraud rings in home health agency (HHA) networks. The system analyzes ownership structures, shared addresses, billing patterns, and exclusion histories to detect coordinated fraud schemes that evade traditional rule-based detection.

Key Results: The system achieves 0.91 ROC-AUC on fraud prediction, 7/7 accuracy on a curated golden set of test cases, and successfully identifies 7 of 8 DOJ-prosecuted Florida HHA fraud facilities in our database.

2. Problem Statement

Medicare fraud costs the U.S. healthcare system an estimated $60-100 billion annually. Home Health Agencies represent the highest-risk provider category, with $17 billion in improper payments reported in 2023. Florida, despite representing only 7% of Medicare beneficiaries, accounts for 40% of all Medicare fraud prosecutions.

Traditional fraud detection systems rely on billing anomaly rules that generate excessive false positives (90%+) and cannot detect coordinated fraud rings operating across multiple shell companies. By the time billing patterns trigger alerts, significant funds have already been extracted from the system.

Our Approach: We shift from reactive billing analysis to proactive structural detection. By modeling provider networks as graphs and analyzing ownership patterns, we can identify fraud rings before they generate billing anomalies. An AI agent layer then investigates flagged networks, generating human-readable investigation briefs with evidence chains.

7. AI Agent Layer

6.1 Agent Architecture

The FraudInvestigator agent uses Claude 3.5 Sonnet to perform structured investigations. Each investigation involves three LLM calls:

  1. Hypothesis Generation: Generate 3 competing fraud hypotheses based on community data
  2. Evidence Evaluation: Evaluate each hypothesis against collected evidence (SUPPORT/REFUTE)
  3. Narrative Synthesis: Write an investigation brief with classification and recommendations

6.2 Red Flag Checklist (Deterministic)

Before any LLM call, the system runs 5 automated checks:

#Red FlagTrigger Condition
1Ownership ConcentrationSingle owner controls 3+ facilities
2Shared AddressMultiple entities with different names at same address
3LEIE ConnectionAny facility or owner on exclusion list
4Billing DeviationBilling > 2 standard deviations from state median
5Shared PhoneMultiple entities sharing phone number

6.3 DOJ Cross-Reference Layer

A local database of 50+ DOJ-prosecuted facilities and individuals is checked BEFORE the ML triage step. If a match is found, the system forces a full investigation regardless of ML risk score. This catches behavioral fraud (kickbacks, phantom billing) that structural analysis misses.

  • Structured Output: Agent must return JSON with required fields (classification, hypotheses, evaluation, narrative)
  • Deterministic Baseline: Red flag results computed before LLM call and injected into context
  • False Positive Rules: System prompt includes healthcare system names to prevent false flags
  • Age Constraint: 30+ year entities cannot be classified as "shell companies"
  • Confidence Calibration: Agent must state confidence level (HIGH/MEDIUM/LOW) with reasoning

11. Limitations & Future Work

10.1 Known Limitations

  • Structural vs. Behavioral Fraud: System detects shell companies and ownership patterns but cannot detect kickbacks or phantom billing without claims-level data
  • Data Freshness: Public datasets lag 30-90 days behind real-time provider changes
  • Geographic Scope: Currently limited to Florida; national expansion requires additional data integration
  • False Positive Rate: Large healthcare systems may trigger flags due to legitimate corporate structure

10.2 Future Enhancements

  1. Claims Integration: Add Medicare FFS claims data for behavioral fraud detection
  2. Temporal Analysis: Track entity cycling and ownership changes over time
  3. Multi-State Expansion: Apply to Texas, California, New York (next highest fraud states)
  4. Real-Time Monitoring: Alert on new high-risk provider registrations
  5. Beneficiary Analysis: Detect patient sharing patterns across fraud rings

12. Conclusion

Provera demonstrates that hybrid ML + agentic AI systems can significantly improve Medicare fraud detection. By combining graph-based machine learning for structural pattern recognition with LLM agents for investigation and explanation, we achieve both high accuracy (0.91 ROC-AUC) and full explainability (100% factual accuracy on generated reports).

The system successfully identifies known fraud patterns (shell company networks, co-located entities) while avoiding false positives on legitimate healthcare organizations. The DOJ cross-reference layer extends detection to behavioral fraud cases that structural analysis alone would miss.

This architecture is scalable to the full national Medicare provider population of 1.2M+ providers and provides a foundation for real-time fraud monitoring in production healthcare environments.
